# DAYSON SPORT

Tienda web estática para GitHub Pages.

## Publicación
1. Extrae este ZIP en tu computador.
2. Copia TODOS los archivos (index.html, app.js, styles.css, logo y fotografías) a la raíz del repositorio.
3. Conserva los nombres exactos de las imágenes; cada uno es único (HS_, HA_ o ROPA_).
4. En GitHub Desktop, realiza Commit y Push.
5. En Settings → Pages, publica desde la rama main y carpeta /(root).

Las fotografías están en la raíz, sin subcarpetas. Las tarjetas muestran la página del catálogo que corresponde a cada referencia; para fotografías de producto aisladas se necesitan fotos individuales de cada producto.
